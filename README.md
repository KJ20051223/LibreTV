# 今天吃什么 · 美食选择器（Android）

一个帮你决定"今天吃什么"的安卓小工具：把常点的外卖店铺和菜品录进去，一键随机抽取。

## 功能

- 🎡 **转盘抽签**：大转盘带逐格震动、减速停靠和撒花动画；可按店铺、分类、预算上限筛选，一次转 1～3 道，可避开最近吃过的 3 道
- 📋 **菜单管理**：添加 / 编辑 / 删除店铺和菜品，菜品可临时停用
- 🤖 **自动采集**（Android 11+）：开启无障碍后，在微信小程序的点餐页点悬浮按钮「开始采集」，
  App 自动下滑、逐屏截图，到底后回到 App 分批交给 AI 识别。只读屏幕和滑动，不点击、不下单。
  Android 13+ 自己安装的 App 开无障碍前，需在「应用信息 → ⋮ → 允许受限制的设置」里放行。
  微信不允许第三方自动化，频繁使用可能有账号风险，请适度使用。
- 📷 **AI 识别菜单**：从相册选菜单截图（支持长截图、多张），AI 只提取店铺、菜品和价格，检查后导入
- 📥 **一键导入**：
  - 在微信、豆包等 App 里长按文字或选中截图 →「分享」→ 选「今天吃什么」，文字直接进导入框，截图直接开始 AI 识别
  - 复制了菜单文字后打开 App，底部会提示「剪贴板里有菜单」，点「导入」即可
  - 也支持从 .txt / .csv / 备份 .json 文件导入；勾选「同名店铺先清空」可整店更新菜单
- 🗂 **菜单可收起**：店铺默认收起，只显示菜品数和价格区间；支持搜索、全部展开/收起、整店启用/停用
- 💾 **备份 / 恢复**：菜单导出成一段文本，换手机时粘贴恢复
- 🕘 **记录**：点「就吃这个」后自动记下吃过什么

菜单数据只保存在手机本地；只有使用 AI 识别时，图片才会发送给你选择的 AI 服务商。

### 批量导入格式

```
【老王黄焖鸡】
黄焖鸡米饭 18
黄焖排骨 22 辣
【兰州拉面】
牛肉拉面 15
```

`【店铺名】` 单独一行；之后每行是 `菜名 价格`，价格可省略，价格后面还可以加分类标签。

## AI 识别设置

在「菜单 → 📷 AI 识别菜单 → AI 设置」里选择服务商并填入自己的 API Key：

| 服务商 | 默认模型 | 说明 |
|---|---|---|
| 智谱 GLM | `glm-4v-flash` | 免费，国内直连 |
| 通义千问（阿里云百炼） | `qwen-vl-max` | 国内直连，按量计费 |
| Claude（Anthropic） | `claude-opus-5-5` | 需能访问 api.anthropic.com |
| 自定义 | — | 任意 OpenAI 兼容的视觉模型接口 |

模型名可以自己改。没有 Key 也能用：点「复制提示词」，把提示词和截图一起发给豆包 / Kimi 等 AI，
再把它的回答粘贴到「批量导入」。导入时也能识别 Markdown 列表和表格。

## 为什么不能自动读取小程序里的菜单？

微信小程序只能在微信客户端内运行，接口依赖微信登录态和签名，外部 App 无法直接获取；
批量抓取也可能违反微信和商家的服务条款。所以这里采用手动录入 / 粘贴导入的方式。

## 下载与构建

- **直接下载**：每次推送代码后，GitHub Actions 会自动构建，APK 发布在仓库的
  [Releases → latest](../../releases/tag/latest) 里，手机下载 `FoodPicker.apk` 安装即可
  （需允许"安装未知来源应用"）。
- **覆盖安装**：APK 用仓库里固定的 `app/release.keystore` 签名，版本号随构建自动递增，
  新版直接装在旧版上面，数据不丢。注意：这把签名密钥是公开的，只从本仓库的 Releases 下载更新。
- **本地构建**：安装 Android SDK 和 Gradle 8.9+ 后执行
  `gradle :app:assembleRelease`，产物在 `app/build/outputs/apk/release/`。
