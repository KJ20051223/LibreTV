# 今天吃什么 · 美食选择器（Android）

一个帮你决定"今天吃什么"的安卓小工具：把常点的外卖店铺和菜品录进去，一键随机抽取。

## 功能

- 🎲 **随机抽签**：按店铺、分类、预算上限筛选，一次抽 1～3 道，可避开最近吃过的 3 道
- 📋 **菜单管理**：添加 / 编辑 / 删除店铺和菜品，菜品可临时停用
- 📥 **批量导入**：把在「扫呗外卖」等小程序里看到的菜单整理成文字，粘贴一次导入
- 💾 **备份 / 恢复**：菜单导出成一段文本，换手机时粘贴恢复
- 🕘 **记录**：点「就吃这个」后自动记下吃过什么

所有数据只保存在手机本地，不联网。

### 批量导入格式

```
【老王黄焖鸡】
黄焖鸡米饭 18 盖饭
黄焖排骨 22 盖饭 辣
【兰州拉面】
牛肉拉面 15 面
```

`【店铺名】` 单独一行；之后每行是 `菜名 价格 分类标签…`，价格和标签都可省略。

## 为什么不能自动读取小程序里的菜单？

微信小程序只能在微信客户端内运行，接口依赖微信登录态和签名，外部 App 无法直接获取；
批量抓取也可能违反微信和商家的服务条款。所以这里采用手动录入 / 粘贴导入的方式。

## 下载与构建

- **直接下载**：每次推送代码后，GitHub Actions 会自动构建，APK 发布在仓库的
  [Releases → latest](../../releases/tag/latest) 里，手机下载 `FoodPicker.apk` 安装即可
  （需允许"安装未知来源应用"）。
- **本地构建**：安装 Android SDK 和 Gradle 8.9+ 后执行
  `gradle :app:assembleRelease`，产物在 `app/build/outputs/apk/release/`。

## 项目结构

```
app/src/main/java/com/foodpicker/app/MainActivity.java  # WebView 外壳
app/src/main/assets/index.html                          # 全部界面与逻辑
.github/workflows/build-apk.yml                         # 自动打包 APK
```
